## 難しかった点、失敗・原因・解決方法・CBDKへの学習

| 分野 | 起きた問題 / 根本原因 | 実際の解決・次回のよりよい進め方 | CBDKへの改善候補（未採用・未実装） |

| メッシュの向き | 元の面構築に隣接面向きの不整合が256辺あり、ASTだけでは判明しなかった | 生成後の実Blenderで向き、非多様体、境界、体積を検査し、旧版形状の比較テストも追加 | QA-MESHを標準の品質ゲートへ |

| エラー時の巻き戻し | `CANCELLED`とERROR報告の組合せで`bpy.ops`が`RuntimeError`を投げることがあった | 故障注入で、例外に加え残骸/選択/アクティブ/再生成まで確認 | QA-FAILUREの共通フィクスチャ |
| CI実行環境 | Privateでランナー未割当、ジョブがsteps=0の段階で失敗 | ランナー不達とコード不具合を明確に区別。公開前に私有データ・パスの混入を点検 | 環境要因を分類する失敗診断・公開前プライバシーチェック |
| Windows描画 | GPUのないWindowsランナーでWorkbenchプレビューが`No OpenGL vendor detected`→アクセス違反で終了 | WindowsではGPUが必要なプレビューだけSKIPし、メッシュ・復旧・旧版比較を維持。Linux Xvfbで画像と画面操作を検査 | CPU-native / GPU-render / interactive GUI の3段ゲート |
| GUI初回起動 | 初回セットアップのモーダルがCtrl+Zを遮ったり、スクリーンショットが全黒になった | GUIモーダルを解消した上でキー送出。X11外部撮影＋PNG内容検査 | QA-GUIに初回状態解消、画像内容とUndo/Redo検査 |
| UI登録の型注釈 | GUIタイマー起動時に、遅延型注釈がBlenderのPropertyGroup登録で`EnumProperty`の名前解決に失敗 | 遅延型注釈を使わず登録時に値を評価。GUI-smokeでは失敗時に即終了 | ヘッドレス/実GUI双方でPropertyGroup登録を実施 |
